OPTIMIZATIONAWS BATCHDISTRIBUTED SYSTEMS

At Amazon, I work on the optimization systems behind real estate allocation. I redesigned the placement model and the infrastructure that runs it, making solutions both more useful and much faster to produce.

SEATTLE, WA / 2026—PRESENT01 / 03
THE PROBLEM

Improve adjacency in placement decisions without increasing relocation cost, while reducing timeouts in a single-process optimizer.

WHAT I BUILT

A mixed-integer model using McCormick linearization, then an AWS Batch pipeline that fans out 23 concurrent solvers sized at runtime. I also turned patterns from 15,000+ code reviews into automated verification rules.

THE IMPACT

12% better clustering at no extra relocation cost. 5× faster runtime. Timeouts fell from 30% to 4%; backtesting found 500+ defects with an 84% acceptance rate.
